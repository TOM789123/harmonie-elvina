# Sources de la refonte (non publiées)

- `images.py` : génère les photos WebP/JPEG de `assets/img/` à partir des originaux du site (branche main).
- `icones.json` : pictogrammes au trait (grille 48), `soin` = mains vectorisées depuis l'icône d'origine.
- `arbre.svg` : arbre de vie vectorisé depuis `icone-arbre.png` (potrace), copié dans `assets/img/arbre.svg`.
- `includes/sprite.php` est généré à partir de `icones.json` (voir l'historique de la conversation / script dans ce dossier).
